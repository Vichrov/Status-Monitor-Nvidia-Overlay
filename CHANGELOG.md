# Changelog

## 0.1.1

- Сокращена русская подпись вентилятора: **Вент.** вместо **Вентилятор**.
  Английская подпись — **Fan**. Изменение действует в HUD и настройках.
- Обновлены README, инструкция и описание релиза.
- GitHub Releases получает установочный ZIP, отдельный `.ovl` для обновления
  без замены пользовательских шрифтов и SHA-256 после прохождения CI.

## 0.1.0

- Четыре NVIDIA-подобных режима, RU/EN и настройки отображения.
- Подключение собственных Regular/Bold TTF/OTF, поддержка кириллицы.
- Показатели адаптированы к Switch; отсутствующие PC-only метрики исключены.
