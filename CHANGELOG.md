# Changelog

## 0.1.2

- Исправлена повторная запись настроек на Switch: rename больше не пытается
  заменить существующий файл. Предыдущая конфигурация сохраняется в .bak
  до установки новой, а при неудаче восстанавливается.
- Меню изменяет состояние в памяти только после успешного сохранения.
- Добавлен код ошибки записи и восстановление .bak при отсутствии nvidia.ini.
- Проверен цикл частоты 10 → 1 → 2 → 5 → 10 → 1 с чтением файла после каждого шага.
- В CI добавлена регрессия no-replace rename, повторные записи и сбои сохранения.

## 0.1.1

- Сокращена русская подпись вентилятора: **Вент.** вместо **Вентилятор**.
  Английская подпись — **Fan**. Изменение действует в HUD и настройках.
- Обновлены README, инструкция и описание релиза.
- GitHub Releases получает установочный ZIP, отдельный `.ovl` для обновления
  без замены пользовательских шрифтов и SHA-256 после прохождения CI.

## 0.1.0

- Четыре NVIDIA-подобных режима, RU/EN и настройки отображения.
- Подключение собственных Regular/Bold TTF/OTF, поддержка кириллицы.
- Показатели адаптированы к Switch; отсутствующие PC-only метрики исключены.
