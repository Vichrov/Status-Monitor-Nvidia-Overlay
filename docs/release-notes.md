Исправлена **«Ошибка записи» при изменении настроек** и возврат к старым
значениям после запуска HUD, в том числе частоты обновления.

### Что исправлено

- Сохранение на Switch больше не пытается переименовать временный файл поверх
  существующего. Используется резервная копия и откат при сбое.
- Параметр в памяти меняется только после успешной записи на SD.
- При ошибке выводится числовой код; при отсутствии основного файла читается .bak.
- Проверен цикл **10 → 1 → 2 → 5 → 10 → 1** с чтением настроек после каждого шага.

### Обновление

Скачайте **Status-Monitor-Nvidia-Overlay.ovl**, замените файл в
**switch/.overlays/** и полностью перезапустите оверлей.
Удалять настройки и шрифты NVIDIA не нужно. Затем снова выберите нужную частоту:
изменения, которые старая версия не записала на SD, восстановить нельзя.

ZIP предназначен для полной установки и содержит свободные шрифты Liberation Sans.
Для сохранения уже установленных оригинальных NVIDIA Sans обновляйте только .ovl.

### Проверки

Сборка devkitA64/libnx; 448 вариантов компоновки; отдельный тест с поведением
rename как на Switch, 40 повторных изменений и загрузок, проверками ошибок,
отката и восстановления резервной копии. Проверка исправления на физической
Switch пользователем ещё требуется.
